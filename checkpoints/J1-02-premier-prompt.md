# J1-02 · 💬 Premier prompt

> 🏅 Badge **Premier prompt** · ⏱ 25 min · Jour 1 « Appareillage » · Niveau N0 Subir · Checkpoint 2 sur 10

🎯 **Objectif** — Demander un chatbot à un chat d'IA sur le web, sans rien d'autre, puis le faire tourner dans votre navigateur.

🧭 **De… à…** — D'un thème provisoire à un chatbot d'une seule page HTML, écrit par le chat et ouvert chez vous, avec la conversation qui l'a produit gardée telle quelle dans le carnet.

🎮 **Le défi** — Demandez comme vous le feriez naturellement, copiez ce que le chat vous rend, regardez ce que cela donne. Ce checkpoint et les deux suivants (J1-03 et J1-04) vous placent volontairement dans la position de celles et ceux qui *subissent* ce que l'IA génère : on demande, on copie, on espère. Ce n'est pas une faute, c'est le point de départ ; les checkpoints suivants mesurent ce que cela vaut. **Ne corrigez rien** : vous gardez tout, vos prompts comme les réponses. C'est le début de l'astuce 13, le journal : ce qu'on a demandé et ce qu'on a obtenu.

🛠 **À faire**

Ce chatbot est un essai jetable : ce n'est pas le Cap Web de votre dossier `atelier`, qui reste tel quel. Un membre du binôme écrit, l'autre note ; échangez à mi-parcours.

1. Ouvrez le [carnet](../carnet.md) et relisez le thème provisoire choisi en J1-01.
2. **Règle de sécurité** : aucune donnée personnelle dans le chat (ni nom, ni adresse, ni téléphone, ni e-mail, réels), aucune clé, aucun mot de passe. Considérez tout ce que vous tapez comme public. Si la page générée **vous demande une clé d'API**, refusez : ne créez ni ne collez aucune clé, et écrivez dans le carnet que la page en demandait une.
3. Ouvrez le chat d'IA sur le web (celui que le formateur indique, à défaut celui que vous connaissez) et démarrez une **nouvelle conversation**.
4. Écrivez votre demande comme vous le feriez naturellement, en une ou deux phrases. Deux choses seulement sont imposées : le thème, et « une seule page HTML que j'ouvre dans mon navigateur ». Par exemple : « Fais-moi un chatbot sur (votre thème), dans une seule page HTML que j'ouvre dans mon navigateur. » Ne cherchez pas à écrire un « bon » prompt : pas encore.
5. Envoyez. Si le chat pose une question, répondez simplement, comme vous le feriez. Ne reprenez pas votre demande après coup.
6. À la racine de votre paquet (le dossier qui contient `README.md` et `atelier`), créez un dossier `essais-n0`. Dans votre éditeur, créez-y un fichier `chatbot-v1.html`, collez le code complet de la réponse, enregistrez. Sans rien changer au code.
7. Ouvrez `essais-n0/chatbot-v1.html` dans le navigateur (double-clic, ou glissez le fichier dans une fenêtre). Cette page tient dans un seul fichier : aucun serveur n'est nécessaire.
8. Utilisez la page deux minutes : envoyez trois messages, dont un sur le thème et un hors thème. Notez ce que vous voyez, sans juger.
9. Dans le carnet, section J1-02, collez **votre prompt** et **la première réponse** du chat, en entier (texte et code), puis vos trois lignes d'observation.
10. Gardez l'onglet du chat ouvert et ne supprimez rien : vous y revenez au checkpoint suivant.

✅ **Preuve** — cochez, ou montrez au formateur
- [ ] Votre prompt et la première réponse du chat sont collés, en entier et tels quels, dans le [carnet](../carnet.md) (section J1-02).
- [ ] `essais-n0/chatbot-v1.html` s'ouvre dans le navigateur et affiche votre chatbot, sur le thème choisi.
- [ ] Le code du fichier est celui que le chat a écrit : rien n'a été corrigé à la main.
- [ ] La conversation collée ne contient ni donnée personnelle ni clé (relue par l'autre membre du binôme).


🆘 **Si ça bloque**
- Le chat répond par plusieurs fichiers, ou par un projet à installer : redemandez « tout dans une seule page HTML, sans rien à installer ». Gardez les deux échanges dans le carnet.
- Le code s'arrête au milieu : écrivez « continue » ou « redonne le code complet en un seul bloc ». Gardez l'échange.
- Page blanche, ou rien ne répond : F12, onglet **Console**, notez le message ; collez-le au chat et demandez de corriger. Gardez cet échange aussi : c'est une observation, pas un échec. Rien ne s'affiche après deux relances : appelez le formateur en montrant vos échanges.
- Le chat demande de créer un compte : demandez d'abord au formateur, et n'entrez aucune donnée personnelle.
- Sinon : votre binôme, le binôme voisin, puis le formateur, en montrant ce que vous avez essayé.

⭐ **Pour aller plus loin** — Demandez au chat : « Explique-moi ce code, ligne par ligne, pour un débutant. » Lisez, puis notez dans le carnet une ligne que vous ne comprenez pas. Ne la corrigez pas : gardez-la, vous la retrouverez plus tard.
