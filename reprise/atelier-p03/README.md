# Atelier de reprise — le squelette de Cap Web

Page structurée, formulaire accessible, liste vide, CSS responsive : l'équivalent du squelette de J1-06. À utiliser seulement si votre atelier ne s'affiche plus correctement : voir la section « Atelier bloqué : la copie de reprise » du `README.md` du jour, à la racine du paquet.

Ce que cette copie **ne contient pas** : « Vous : … » ni le refus du message vide (checkpoint J1-09), le cerveau, les modules, la mémoire. Reprenez au checkpoint J1-07 (Petits pas), avec l'agent, puis suivez les checkpoints dans l'ordre.

Deux points à connaître :

- La limite est écrite en dur à **280 caractères** (libellé et `maxlength` de `public/index.html`). Alignez-la sur votre cahier personnel par une demande ciblée à l'agent.
- Les tests du navigateur de `browser/` (facultatifs, `npm run test:browser`) attendent encore 280 : une fois la limite changée, ne les comptez pas comme une erreur. `npm test` accepte n'importe quelle valeur de `maxlength`.

Depuis ce dossier, une fois copié à la place de `atelier` : `npm start`, puis `http://127.0.0.1:3000`.
